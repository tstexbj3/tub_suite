## ภาพรวม

### หน้าที่ของคุณ
ในฐานะ **พนักงานตรวจสอบ** คุณมีหน้าที่:
- ✅ ตรวจสอบอุปกรณ์ตามกำหนดการผ่านอุปกรณ์มือถือ
- ✅ สแกน QR Code บนอุปกรณ์เพื่อเข้าถึงรายการตรวจสอบ
- ✅ ถ่ายรูปพร้อมประทับเวลาระหว่างการตรวจสอบ
- ✅ แจ้งปัญหาอุปกรณ์พร้อมรูปภาพ
- ✅ ยืนยันการซ่อมแซมที่เสร็จสมบูรณ์

### สิ่งที่คุณไม่ต้องทำ
- ❌ คุณไม่ต้องใช้ระบบ ERPNext แบบ Desktop
- ❌ คุณไม่ต้องอนุมัติหรือมอบหมายงานซ่อม
- ❌ คุณไม่ต้องทำการซ่อมแซมเอง

**[ภาพหน้าจอ 1: เบราว์เซอร์มือถือพร้อม URL พอร์ทัล]**

### ขั้นตอนที่ 2: เข้าสู่ระบบ
1. ป้อนชื่อผู้ใช้ของคุณ (ได้รับจากแผนก IT)
2. ป้อนรหัสผ่าน
3. แตะ **เข้าสู่ระบบ**

**[ภาพหน้าจอ 2: หน้าจอเข้าสู่ระบบ]**

### ขั้นตอนที่ 3: ดูแดชบอร์ด

- 📋 **รายการอุปกรณ์** - อุปกรณ์ทั้งหมดที่ได้รับมอบหมาย
- 🔍 **ช่องค้นหา** - ค้นหาอุปกรณ์แบบเร็ว

**[ภาพหน้าจอ 3: แดชบอร์ดพร้อมตัวเลขแจ้งเตือน]**

## งานตรวจสอบประจำวัน

### ขั้นตอนที่ 1: สแกน QR Code ของอุปกรณ์
1. แตะปุ่ม **สแกน QR** ด้านบน
2. ชี้กล้องไปที่ QR Code บนสติกเกอร์อุปกรณ์
3. รอระบบอ่านอัตโนมัติ

**[ภาพหน้าจอ 4: หน้าจอสแกน QR]**

**เคล็ดลับ:** หากสแกน QR ไม่ได้ ให้ใช้ช่องค้นหาพิมพ์รหัสอุปกรณ์แทน

### ขั้นตอนที่ 2: ดูรายละเอียดอุปกรณ์
หลังจากสแกน คุณจะเห็น:
- 📷 **รูปภาพอุปกรณ์**
- 📝 **ชื่อและรหัสอุปกรณ์**
- ✅ **รายการตรวจสอบ** (ถ้าอุปกรณ์พร้อมใช้งาน)
- ⚠️ **คำเตือนปัญหา** (ถ้าอุปกรณ์เสีย)

**[ภาพหน้าจอ 5: หน้ารายละเอียดอุปกรณ์ - อุปกรณ์ปกติ]**

**[ภาพหน้าจอ 6: หน้ารายละเอียดอุปกรณ์ - อุปกรณ์ที่มีการซ่อมแซม]**

### ขั้นตอนที่ 3: ทำการตรวจสอบ (ไม่มีปัญหา)
ถ้าทุกอย่างทำงานปกติ:

1. ตรวจสอบแต่ละรายการ:
   - ตรวจสอบระดับน้ำมันเครื่อง
   - ตรวจสอบแรงดันลมยาง
   - ตรวจสอบน้ำมันเบรก
   - ฯลฯ

2. แตะปุ่ม **📷 ถ่ายรูป**
3. ถ่ายรูป **ก่อนเริ่มงาน** (สภาพเริ่มต้น)
4. ทำงานบำรุงรักษา
5. แตะปุ่ม **📷 ถ่ายรูป** อีกครั้ง
6. ถ่ายรูป **หลังเสร็จงาน** (สภาพหลังเสร็จ)

**[ภาพหน้าจอ 7: รายการตรวจสอบพร้อมปุ่มถ่ายรูป]**

**[ภาพหน้าจอ 8: หน้าจอกล้องถ่ายรูป]**

**สำคัญ:** รูปภาพจะถูกประทับเวลาและตำแหน่งโดยอัตโนมัติ

### ขั้นตอนที่ 4: เพิ่มหมายเหตุการตรวจสอบ
1. เลื่อนไปที่ช่อง **หมายเหตุ**
2. ป้อนข้อสังเกต เช่น:
   - "ระบบทั้งหมดปกติ"
   - "พบรอยรั่วน้ำมันเล็กน้อย แต่ยังใช้งานได้"
   - "เปลี่ยนยางระหว่างตรวจสอบ"

**[ภาพหน้าจอ 9: ช่องหมายเหตุ]**

### ขั้นตอนที่ 5: ส่งงาน
1. แตะปุ่ม **ส่งงาน** ด้านล่าง
2. รอข้อความยืนยัน: "✅ ส่งงานสำเร็จ"
3. การ์ดงานจะ**ถูกล็อก**จนถึงวันพรุ่งนี้

**[ภาพหน้าจอ 10: ปุ่มส่งและข้อความสำเร็จ]**

## การแจ้งปัญหา

### เมื่อใดควรแจ้งปัญหา
แจ้งปัญหาเมื่อพบ:
- ❌ อุปกรณ์ไม่ทำงาน
- ⚠️ อันตรายด้านความปลอดภัย
- 🔧 ชิ้นส่วนเสียหรือหายไป
- 🛑 อุปกรณ์ไม่สามารถใช้งานได้อย่างปลอดภัย

### ขั้นตอนที่ 1: เลือก "มีปัญหา"
1. แตะสวิตช์: **งานนี้มีปัญหา**
2. ฟอร์มจะเปลี่ยนเป็นแสดงช่องปัญหา

**[ภาพหน้าจอ 11: ปุ่มสวิตช์ปัญหา - ปิด]**

**[ภาพหน้าจอ 12: ปุ่มสวิตช์ปัญหา - เปิดพร้อมช่องปัญหา]**

### ขั้นตอนที่ 2: ถ่ายรูปปัญหา
1. แตะปุ่ม **📷 ถ่ายรูป** ในส่วน **รูปปัญหา**
2. ถ่ายรูปที่ชัดเจนแสดง:
   - ชิ้นส่วนที่เสีย
   - ข้อความแสดงข้อผิดพลาด (ถ้ามี)
   - สภาพโดยรวม

**ขั้นต่ำ:** ต้องมี 1 รูป
**แนะนำ:** 2-3 รูปจากมุมต่างๆ

**[ภาพหน้าจอ 13: ส่วนรูปปัญหา]**

**[ภาพหน้าจอ 14: ตัวอย่างรูปปัญหา - ชิ้นส่วนเสีย]**

### ขั้นตอนที่ 3: อธิบายปัญหา
ในช่อง **คำอธิบายปัญหา** เขียน:
- **อะไรเสีย:** "ยางหน้าแบน"
- **สิ่งที่พบ:** "ได้ยินเสียงฟู่ ยางแบนสนิท"
- **เกิดเมื่อไร:** "พบระหว่างตรวจสอบเช้า"

**ตัวอย่าง:**
```
ยางหน้าซ้ายแบนสนิท พบระหว่างตรวจสอบเช้า
ยางดูเหมือนมีรูรั่ว รถไม่สามารถใช้งานได้
อย่างปลอดภัย
```

**[ภาพหน้าจอ 15: ช่องคำอธิบายปัญหาที่กรอกแล้ว]**

### ขั้นตอนที่ 4: เพิ่มหมายเหตุการตรวจสอบ (ถ้ามี)
ใช้ช่อง **หมายเหตุ** สำหรับบริบทเพิ่มเติม:
- "อุปกรณ์ทำงานดีเมื่อวาน"
- "ผู้ปฏิบัติงานรายงานเสียงแปลกเมื่อวาน"

**[ภาพหน้าจอ 16: ช่องหมายเหตุสำหรับการแจ้งปัญหา]**

### ขั้นตอนที่ 5: ส่งรายงานปัญหา
1. แตะปุ่ม **ส่งงาน**
2. รอการยืนยัน
3. คุณจะเห็น:
   - ✅ "แจ้งปัญหาสำเร็จ"
   - 🔔 "แจ้งช่างเรียบร้อยแล้ว"

**[ภาพหน้าจอ 17: ข้อความส่งปัญหาสำเร็จ]**

### จะเกิดอะไรต่อไป?
1. **สถานะอุปกรณ์** เปลี่ยนเป็น "เสีย"
2. **ทีมช่าง** จะได้รับการแจ้งเตือน
3. **คำขอซ่อม** จะถูกสร้างอัตโนมัติ
4. **คุณจะได้รับแจ้ง** เมื่อซ่อมเสร็จเพื่อตรวจสอบ

## การยืนยันการซ่อมแซม

### เมื่อใดคุณต้องยืนยัน?
หลังจากช่างซ่อมเสร็จ คุณจะได้รับการแจ้งเตือน:
- 🔔 "ซ่อมเสร็จแล้ว - กรุณาตรวจสอบ"
- 📱 ตัวเลขแจ้งเตือนจะเพิ่มขึ้น

**[ภาพหน้าจอ 18: ตัวเลขแจ้งเตือนสำหรับการยืนยัน]**

### ขั้นตอนที่ 1: สแกนอุปกรณ์อีกครั้ง
1. กลับไปที่ตำแหน่งอุปกรณ์
2. สแกน QR Code
3. คุณจะเห็นข้อมูลการซ่อม

**[ภาพหน้าจอ 19: หน้าอุปกรณ์แสดงการซ่อมที่เสร็จแล้ว]**

### ขั้นตอนที่ 2: ทดสอบอุปกรณ์
1. ตรวจสอบว่าปัญหาได้รับการแก้ไขจริงหรือไม่
2. ทดสอบการทำงานของอุปกรณ์
3. ตรวจสอบคุณภาพการซ่อม

### ขั้นตอนที่ 3: เลือกผลการยืนยัน

#### ตัวเลือก A: ผ่าน ✅
ถ้าการซ่อมดี:
1. แตะปุ่ม **ผ่าน**
2. สถานะอุปกรณ์กลับเป็น "พร้อมใช้งาน"
3. การ์ดงานปลดล็อกสำหรับการตรวจสอบปกติ

**[ภาพหน้าจอ 20: ปุ่มยืนยัน - เลือกผ่าน]**

#### ตัวเลือก B: ไม่ผ่าน ❌
ถ้าปัญหายังไม่ได้รับการแก้ไข:
1. แตะปุ่ม **ไม่ผ่าน**
2. ถ่ายรูปแสดงปัญหาที่เหลืออยู่
3. เพิ่มหมายเหตุอธิบายว่าอะไรยังผิดอยู่
4. ช่างจะได้รับแจ้งอีกครั้ง

**[ภาพหน้าจอ 21: ปุ่มยืนยัน - เลือกไม่ผ่าน]**

**[ภาพหน้าจอ 22: การยืนยันไม่ผ่านพร้อมหมายเหตุ]**

## การแก้ไขปัญหา

### ปัญหา: สแกน QR Code ไม่ได้
**วิธีแก้:**
1. เช็ดสติกเกอร์ QR Code ให้สะอาด
2. ตรวจสอบแสงสว่างเพียงพอ
3. ถือโทรศัพท์นิ่งๆ ห่างประมาณ 15-30 ซม.
4. ใช้ฟังก์ชัน **ค้นหา** แทน:
   - แตะช่องค้นหา
   - พิมพ์รหัสอุปกรณ์ (เช่น "PUMP-001")
   - เลือกจากผลลัพธ์

**[ภาพหน้าจอ 23: ฟังก์ชันค้นหาเป็นทางเลือกแทน QR]**

### ปัญหา: กล้องไม่ทำงาน
**วิธีแก้:**
1. ตรวจสอบสิทธิ์เบราว์เซอร์:
   - การตั้งค่า → Safari/Chrome → กล้อง → อนุญาต
2. ปิดและเปิดเบราว์เซอร์ใหม่
3. ลองเบราว์เซอร์อื่น
4. รีสตาร์ทโทรศัพท์

**[ภาพหน้าจอ 24: การตั้งค่าสิทธิ์กล้องของเบราว์เซอร์]**

### ปัญหา: ข้อผิดพลาด "ต้องมีรูปภาพ"
**วิธีแก้:**
- การตรวจสอบปกติ: ต้องถ่าย **อย่างน้อย 2 รูป** (ก่อน/หลัง)
- การแจ้งปัญหา: ต้องถ่าย **อย่างน้อย 1 รูป** (รูปปัญหา)

**[ภาพหน้าจอ 25: ข้อความแจ้งเตือนต้องมีรูปภาพ]**

### ปัญหา: การ์ดงานไม่ปลดล็อก
**เหตุผล:** งานล็อกหลังทำเสร็จจนถึงวันครั้งถัดไป

**ตรวจสอบ:**
1. ดูความถี่งาน (รายวัน, รายสัปดาห์, รายเดือน)
2. วันที่ทำล่าสุด
3. วันที่ครบกำหนดถัดไป

**ติดต่อ IT** ถ้างานควรจะเปิดแต่ไม่เปิด

**[ภาพหน้าจอ 26: การ์ดงานที่ล็อกพร้อมข้อมูลกำหนดการ]**

### ปัญหา: ข้อความ "อุปกรณ์เสีย"
**ความหมาย:** อุปกรณ์มีการซ่อมแซมอยู่

**ควรทำอย่างไร:**
1. อย่าทำการบำรุงรักษา
2. ตรวจสอบสถานะการซ่อม
3. รอช่างทำงานเสร็จ
4. คุณจะได้รับแจ้งเมื่อพร้อมตรวจสอบ

**[ภาพหน้าจอ 27: หน้าจอคำเตือนอุปกรณ์เสีย]**

### ปัญหา: ส่งงานไม่ได้
**สาเหตุทั่วไป:**
1. ❌ ขาดรูปภาพที่ต้องการ
2. ❌ ไม่ได้กรอกคำอธิบาย (ถ้าแจ้งปัญหา)
3. ❌ สัญญาณอินเทอร์เน็ตขาด
4. ❌ เซสชันหมดอายุ

**วิธีแก้:**
1. ตรวจสอบว่ากรอกครบทุกช่อง
2. ตรวจสอบการเชื่อมต่อ WiFi/มือถือ
3. รีเฟรชหน้าและลองใหม่
4. ออกจากระบบและเข้าใหม่

**[ภาพหน้าจอ 28: ข้อความแสดงข้อผิดพลาดเครือข่าย]**

## คู่มือฉบับย่อ

7. ส่งงาน

6. ส่งงาน
```

3. ทดสอบอุปกรณ์
4. เลือก: ผ่าน หรือ ไม่ผ่าน
5. ส่งการยืนยัน
```
