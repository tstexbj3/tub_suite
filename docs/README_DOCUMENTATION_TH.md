## เอกสารทางเทคนิค

### สำหรับนักพัฒนาและเจ้าหน้าที่ IT

#### การติดตั้งและการตั้งค่า
- **[DEPLOYMENT_GUIDE_v2.1.0.md](DEPLOYMENT_GUIDE_v2.1.0.md)** - ขั้นตอนการติดตั้งการใช้งานจริงสำหรับ v2.1.0
- **[FIXTURE_MANAGEMENT.md](FIXTURE_MANAGEMENT.md)** - การจัดการช่องปรับแต่งและ workflows ข้ามสภาพแวดล้อม

#### สถาปัตยกรรมระบบ
- **Frontend:** React 19 พร้อมเครื่องสแกน QR และการรวมกล้อง
- **Backend:** ERPNext v15 / Frappe Framework v15
- **ฐานข้อมูล:** MariaDB
- **การแคช:** Redis
- **เว็บเซิร์ฟเวอร์:** Nginx

#### คุณสมบัติหลัก
- ✅ พอร์ทัลพนักงานตรวจสอบมือถือพร้อมการสแกน QR
- ✅ การจับภาพรูปภาพพร้อมประทับเวลาอัตโนมัติและตำแหน่ง
- ✅ ขั้นตอนการอนุมัติหลายขั้น (Draft → รออนุมัติ → อนุมัติแล้ว → เสร็จสิ้น)
- ✅ การล็อกช่องตามบทบาท (ช่างไม่สามารถแก้ไขช่องผู้จัดการ)
- ✅ การแจ้งเตือนอัตโนมัติในแต่ละขั้นตอน
- ✅ การจัดการสถานะอุปกรณ์ (เสีย / กำลังบำรุงรักษา)
- ✅ วงรอบการยืนยันพนักงานตรวจสอบ (การประกันคุณภาพแบบปิด)

## ความต้องการของระบบ

### เซิร์ฟเวอร์การใช้งานจริง
- **ระบบปฏิบัติการ:** Ubuntu 24.04 LTS (หรือคล้ายกัน)
- **RAM:** 4GB ขั้นต่ำ, 8GB แนะนำ
- **ดิสก์:** 50GB ขั้นต่ำ (สำหรับฐานข้อมูล ไฟล์ การสำรอง)
- **Python:** 3.11+
- **Node.js:** 18+
- **ฐานข้อมูล:** MariaDB 10.6+
- **แคช:** Redis 7+

### อุปกรณ์ลูกค้า

#### พนักงานตรวจสอบ (มือถือ)
- **อุปกรณ์:** สมาร์ทโฟนหรือแท็บเล็ต
- **ระบบปฏิบัติการ:** iOS 14+ หรือ Android 10+
- **เบราว์เซอร์:** Chrome, Safari, Edge (เวอร์ชันล่าสุด)
- **กล้อง:** ต้องการสำหรับการจับภาพรูปภาพ
- **อินเทอร์เน็ต:** WiFi หรือ 4G/5G มือถือ

#### ช่าง/ผู้จัดการ (Desktop)
- **อุปกรณ์:** แล็ปท็อปหรือคอมพิวเตอร์เดสก์ท็อป
- **ระบบปฏิบัติการ:** Windows, macOS, Linux
- **เบราว์เซอร์:** Chrome, Firefox, Edge (เวอร์ชันล่าสุด)
- **หน้าจอ:** 1280x720 ขั้นต่ำ, 1920x1080 แนะนำ

## คำถามที่พบบ่อย

### สำหรับพนักงานตรวจสอบ

**ถ: ฉันสามารถใช้บนโทรศัพท์ของฉันได้หรือไม่?**
ต: ได้! พอร์ทัลพนักงานตรวจสอบออกแบบสำหรับอุปกรณ์มือถือ ใช้พอร์ทัล `/maintenance`

**ถ: ฉันต้องการแอปหรือไม่?**
ต: ไม่ต้องการแอป ใช้เบราว์เซอร์มือถือของคุณ (Chrome, Safari ฯลฯ)

**ถ: ถ้า QR code เสียหายล่ะ?**
ต: ใช้ช่องค้นหาพิมพ์รหัสอุปกรณ์ด้วยตนเอง

**ถ: ฉันต้องการรูปภาพกี่รูป?**
ต: การตรวจสอบปกติ: อย่างน้อย 2 รูป (ก่อน/หลัง) การรายงานปัญหา: อย่างน้อย 1 รูป (รูปปัญหา)

### สำหรับช่าง

**ถ: ฉันสามารถแก้ไขการซ่อมหลังส่งขออนุมัติได้หรือไม่?**
ต: ไม่ได้ หลังจากส่ง ฟอร์มจะถูกล็อกจนกว่าผู้จัดการอนุมัติ/ไม่อนุมัติ

**ถ: ถ้าผู้จัดการไม่อนุมัติงานของฉันล่ะ?**
ต: ตรวจสอบหมายเหตุการไม่อนุมัติ แก้ไข และส่งใหม่

**ถ: ฉันสามารถอนุมัติการซ่อมของตัวเองได้หรือไม่?**
ต: ไม่ได้ ต้องมีการอนุมัติของผู้จัดการสำหรับการซ่อมทั้งหมด

### สำหรับผู้จัดการ

**ถ: ฉันสามารถแก้ไขเอกสารงานของช่างได้หรือไม่?**
ต: ไม่ได้ ช่องช่างถูกล็อกเพื่อการตรวจสอบย้อนกลับ คุณสามารถอนุมัติ/ไม่อนุมัติและเพิ่มหมายเหตุของคุณเท่านั้น

**ถ: ฉันควรตรวจสอบการอนุมัติที่รออยู่เร็วแค่ไหน?**
ต: ความรุนแรงสูง: ภายใน 2-4 ชั่วโมง (อุปกรณ์หยุด) ความรุนแรงต่ำ: วันเดียวกัน

**ถ: ฉันสามารถยกเลิกการอนุมัติได้หรือไม่?**
ต: ไม่ได้ Workflow ไม่อนุญาตให้ย้อนกลับสถานะ คุณสามารถแก้ไขหมายเหตุการอนุมัติของคุณหลังจากนั้น
