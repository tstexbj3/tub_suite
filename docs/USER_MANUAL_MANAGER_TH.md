## ภาพรวม

### หน้าที่ของคุณ
ในฐานะ **ผู้จัดการบำรุงรักษา** คุณมีหน้าที่:
- ✅ ตรวจสอบงานซ่อมที่ช่างส่งมา
- ✅ อนุมัติงานซ่อมที่มีคุณภาพและเอกสารครบถ้วน
- ✅ ไม่อนุมัติงานซ่อมที่ไม่สมบูรณ์หรือไม่ปลอดภัย
- ✅ ให้คำติชมแก่ช่าง
- ✅ ติดตามประสิทธิภาพการบำรุงรักษาโดยรวม
- ✅ ตรวจสอบการปฏิบัติตามมาตรฐาน

### สิ่งที่คุณไม่ต้องทำ
- ❌ คุณไม่ต้องทำการซ่อมจริง (ช่างทำ)
- ❌ คุณไม่ต้องยืนยันการซ่อมที่เสร็จแล้ว (พนักงานตรวจสอบทำ)
- ❌ คุณไม่สามารถแก้ไขรายงานของพนักงานตรวจสอบ

### สิทธิ์ของคุณ
คุณมี **สิทธิ์เต็ม** ในการ:
- ดูการซ่อมทั้งหมด (Draft, รออนุมัติ, อนุมัติแล้ว, เสร็จสิ้น, ไม่อนุมัติ)
- อนุมัติหรือไม่อนุมัติงานช่าง
- แก้ไขหมายเหตุและลายเซ็นการอนุมัติ
- ดูรายงานระบบทั้งหมด
- ล็อก/ปลดล็อกช่องที่มีการป้องกัน

คุณ **ไม่สามารถแก้ไข** (เพื่อการปฏิบัติตามข้อกำหนด):
- รายงานปัญหาเดิมของพนักงานตรวจสอบ
- เอกสารงานของช่าง
- วันที่/เวลาเสีย
- ช่อง รายงานโดย

### ขั้นตอนการทำงานของคุณ
```
1. รับการแจ้งเตือน → ช่างส่งขออนุมัติ
2. ตรวจสอบเอกสาร → ดูรูปภาพ หมายเหตุ อะไหล่ที่ใช้
3. ประเมินคุณภาพ → งานเสร็จสมบูรณ์และปลอดภัยหรือไม่?
4. ตัดสินใจ:
   ├─ อนุมัติ → เพิ่มลายเซ็น + หมายเหตุ → ช่างทำเครื่องหมายเสร็จสิ้น
   └─ ไม่อนุมัติ → เพิ่มเหตุผล → ช่างทำใหม่หรือยกเลิก
5. ติดตามการยืนยัน → พนักงานตรวจสอบทดสอบการซ่อม
```

**[ภาพหน้าจอ 8: ส่วนหัวการซ่อม]**

3. มองหาไฟล์ที่ชื่อ "Issue Photo 1", "Issue Photo 2" ฯลฯ
4. คลิกเพื่อดูขนาดเต็ม

**คำถามที่ต้องถาม:**
- ปัญหาที่รายงานมองเห็นในรูปภาพหรือไม่?
- เป็นปัญหาจริงหรือเป็นเหตุการณ์เท็จ?
- ความรุนแรงตรงกับปัญหาหรือไม่?

**[ภาพหน้าจอ 9: รูปภาพปัญหาจากพนักงานตรวจสอบ]**

2. ตรวจสอบแต่ละแถว:

| คอลัมน์ | สิ่งที่ต้องตรวจสอบ |
|---|---|
| **การดำเนินการ** | การดำเนินการที่วางแผนเหมาะสมหรือไม่? |
| **อะไหล่ที่ต้องการ** | อะไหล่ถูกต้องและเพียงพอหรือไม่? |
| **เวลาโดยประมาณ** | เวลาโดยประมาณสมเหตุสมผลหรือไม่? |

**สัญญาณเตือน:**
- ❌ การดำเนินการว่างเปล่าหรือคลุมเครือ ("ซ่อมมัน")
- ❌ ไม่มีรายการอะไหล่
- ❌ เวลาโดยประมาณไม่สมจริง

- การทดสอบที่ทำ
- ผลการทดสอบ

**เอกสารแย่:**
- คลุมเครือ ("แก้ไขปัญหา")
- ขาดรายละเอียด
- ไม่มีการกล่าวถึงการทดสอบ

## การอนุมัติการซ่อม

### เมื่อใดควรอนุมัติ
อนุมัติเมื่อเกณฑ์ทั้งหมดตรงตาม:
- ✅ เอกสารสมบูรณ์และละเอียด
- ✅ ใช้อะไหล่ที่เหมาะสม
- ✅ งานได้รับการทดสอบ
- ✅ รูปภาพแสดงการซ่อมที่เสร็จสมบูรณ์
- ✅ มีลายเซ็นช่าง
- ✅ ไม่มีความกังวลด้านความปลอดภัย
- ✅ งานตรงกับปัญหาเดิม

### ขั้นตอนที่ 1: เลื่อนไปที่ส่วนการอนุมัติของผู้จัดการ
ส่วนนี้ **มองเห็นได้เฉพาะผู้จัดการ**

**[ภาพหน้าจอ 16: ตำแหน่งส่วนการอนุมัติของผู้จัดการ]**

คลิกในช่อง **หมายเหตุการอนุมัติ** และเขียน:
- สิ่งที่คุณตรวจสอบแล้ว
- ข้อสังเกตใดๆ

```
เอกสารละเอียดครบถ้วน รูปภาพแสดงงานที่เสร็จสมบูรณ์อย่างชัดเจน
```

## การไม่อนุมัติการซ่อม

### เมื่อใดควรไม่อนุมัติ
ไม่อนุมัติเมื่อ:
- ❌ เอกสารไม่เพียงพอ
- ❌ รูปภาพขาดหายหรือไม่ชัด
- ❌ ใช้อะไหล่ผิด
- ❌ งานไม่ได้ทดสอบ
- ❌ ความกังวลด้านความปลอดภัย
- ❌ งานไม่ตรงกับปัญหา
- ❌ เป็นเหตุการณ์เท็จ (ปัญหาไม่มีจริง)

### ขั้นตอนที่ 1: เพิ่มหมายเหตุการไม่อนุมัติ
คลิกในช่อง **หมายเหตุการอนุมัติ** และเขียน:
- **ทำไม** คุณไม่อนุมัติ
- **อะไร** ต้องการการแก้ไข
- **อย่างไร** ช่างควรแก้ไข

**ตัวอย่างสำหรับเอกสารไม่เพียงพอ:**
```
ไม่อนุมัติ - เอกสารไม่เพียงพอ

ปัญหา:
1. การดำเนินการที่ทำคลุมเครือเกินไป - ต้องการรายละเอียดทีละขั้น
2. ไม่มีรูปภาพความสมบูรณ์แสดงชิ้นส่วนที่ติดตั้ง
3. ไม่มีการอธิบายการทดสอบ - คุณรู้ได้อย่างไรว่าแก้ไขแล้ว?

ต้องการสำหรับการส่งใหม่:

ส่งใหม่หลังจากแก้ไขรายการเหล่านี้
```

## การติดตามระบบ

### ภาพรวมแดชบอร์ด
**วิธีที่ 1: รายการ Asset Repair**
1. ไปที่รายการ Asset Repair
2. ใช้การรวมตัวกรองเหล่านี้:

**[ภาพหน้าจอ 28: รายการ Asset Repair พร้อมตัวกรองหลายตัว]**

| มุมมอง | ตัวกรอง | วัตถุประสงค์ |
|---|---|---|
| **รอการตรวจสอบของฉัน** | Workflow State = รออนุมัติ | ต้องการการกระทำของคุณ |
| **อนุมัติล่าสุด** | Workflow State = อนุมัติแล้ว + แก้ไขสัปดาห์ที่แล้ว | ติดตามการอนุมัติล่าสุด |
| **รายการไม่อนุมัติ** | Workflow State = ไม่อนุมัติ | ติดตามการทำใหม่ |
| **เสร็จเดือนนี้** | Workflow State = เสร็จสิ้น + แก้ไขเดือนนี้ | ติดตามประสิทธิภาพ |
| **ปัญหารุนแรง** | ความรุนแรงปัญหา = รุนแรง | การซ่อมสำคัญ |

## การแก้ไขปัญหา

### ปัญหา: "ไม่สามารถแก้ไขช่องการอนุมัติ"
**สาเหตุที่เป็นไปได้:**

1. **บทบาทผิด**
   - ตรวจสอบ: การตั้งค่า → ผู้ใช้ → โปรไฟล์ของคุณ → บทบาท
   - ต้องการ: "ผู้จัดการบำรุงรักษา" หรือ "ผู้จัดการคุณภาพ"

2. **เอกสารในสถานะ Draft**
   - ส่วนการอนุมัติปรากฏเฉพาะในสถานะรออนุมัติ
   - รอช่างส่ง

**[ภาพหน้าจอ 40: การตรวจสอบบทบาทในโปรไฟล์ผู้ใช้]**

---

### ปัญหา: ไม่ได้รับการแจ้งเตือน
**ตรวจสอบ:**
1. ไอคอนกระดิ่ง (🔔) → ตรวจสอบแท็บ "ทั้งหมด"
2. การตั้งค่าการแจ้งเตือน → เปิดใช้งานการแจ้งเตือนอีเมลหรือไม่?
3. ไปที่รายการ Asset Repair → กรองรออนุมัติด้วยตนเอง

**[ภาพหน้าจอ 41: การตั้งค่าการแจ้งเตือน]**

---

### ปัญหา: ไม่สามารถเปลี่ยนสถานะ Workflow
**ข้อผิดพลาด:** "เอกสารนี้ต้องถูกส่ง"

**วิธีแก้:**
เอกสารยังอยู่ใน Draft ช่างต้อง:
1. เพิ่มลายเซ็นช่าง
2. คลิกปุ่ม "ส่งขออนุมัติ"

**[ภาพหน้าจอ 42: ข้อผิดพลาดเอกสารไม่ได้ส่ง]**

## คู่มือฉบับย่อ

### ขั้นตอนการอนุมัติ
```
1. เปิดการซ่อมรออนุมัติ
2. ตรวจสอบรูปภาพปัญหา (พนักงานตรวจสอบ)
3. ตรวจสอบแผนทางวิศวกรรม
4. ตรวจสอบการดำเนินการที่ทำ
5. ตรวจสอบรูปภาพความสมบูรณ์
6. ตรวจสอบลายเซ็นช่าง
7. ตัดสินใจ: อนุมัติ หรือ ไม่อนุมัติ
8. เพิ่มหมายเหตุการอนุมัติ (โดยละเอียด)
9. เพิ่มลายเซ็นการอนุมัติ
10. บันทึกเอกสาร
11. คลิกปุ่ม อนุมัติ/ไม่อนุมัติ
```

### รายการตรวจสอบการไม่อนุมัติ
```
ในหมายเหตุการอนุมัติ รวม:
- ทำไม ไม่อนุมัติ
- อะไร ไม่เพียงพอ
- อย่างไร แก้ไข
- อะไร ต้องรวมในการส่งใหม่
```

### งานผู้จัดการประจำวัน
```
เช้า:
- ตรวจสอบการอนุมัติที่รออยู่
- จัดลำดับความสำคัญตามความรุนแรง
- ตรวจสอบเร่งด่วน (รุนแรง) ก่อน

ตลอดวัน:
- ตอบการตรวจสอบที่รออยู่
- ให้คำติชมแก่ช่าง
- ติดตามสถานะอุปกรณ์

ปลายวัน:
- ล้างการอนุมัติที่รออยู่ทั้งหมด
- ตรวจสอบการติดตามการไม่อนุมัติ
- ตรวจสอบสรุปประจำวัน
```
