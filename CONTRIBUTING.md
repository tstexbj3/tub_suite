# Contributing to TUB Suite

Thank you for your interest in contributing to TUB Suite!

## Development Setup

1. Clone the repository
2. Install to your Frappe bench
3. Create a test site
4. Install dependencies

See [docs/INSTALLATION.md](docs/INSTALLATION.md) for detailed setup.

## Code Standards

- **Python**: Follow PEP 8
- **JavaScript**: ES6+ syntax
- **Documentation**: Markdown format
- **Commits**: Use Conventional Commits

## Testing

Before submitting:
1. Test all features manually
2. Check browser console for errors
3. Test on mobile devices
4. Verify QR scanning works

## Pull Request Process

1. Create a feature branch
2. Make your changes
3. Test thoroughly
4. Submit PR with detailed description
